# hulladb_protocol

Shared function and synchronization protocol contracts for hulladb.

Since 0.1.1 this crate reexports `hulladb_schema::protocol`, also available as
`hulladb::protocol`. Existing imports refer to the same shared types.

See the [repository](https://github.com/hulladev/db) for setup, examples and the architecture.
The application-facing Rust SDK is [`hulladb`](https://docs.rs/hulladb).
