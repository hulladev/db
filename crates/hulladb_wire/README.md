# hulladb_wire

Lossless tagged JSON record codecs for hulladb.

Since 0.1.1 this crate reexports `hulladb_schema::wire`, also available as
`hulladb::wire`. Existing imports and encoded records remain supported.

See the [repository](https://github.com/hulladev/db) for setup, examples and the architecture.
The application-facing Rust SDK is [`hulladb`](https://docs.rs/hulladb).
